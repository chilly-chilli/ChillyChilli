物权变动，是物权与特定主体、客体和内容之间法律关系的动态变化。学习本章，核心不是背“登记、交付”四个字，而是把三条主线连起来：

1. **为什么要公示**：物权具有对世效力，物权变动会影响不特定第三人的交易安全。
2. **公示附着在哪里**：主要附着于基于法律行为发生的物权变动；裁判、继承、事实行为等非基于法律行为的变动另有规则。
3. **物权变动的效力来源是什么**：买卖合同本身、独立物权合意，还是债权合意加登记/交付，这是物权变动模式与物权行为理论要回答的问题。

# 一、物权变动概述

## （一）物权变动的含义

物权变动，是指物权的**发生、内容变更与消灭**。民法典物权编的立法语言表述为“物权的设立、变更、转让和消灭”。

- **发生**：物权与特定主体结合。
  - 所有权通常说“取得”，不说“设立”。
  - 定限物权通常说“设立”，如建设用地使用权、居住权、地役权的设立。
- **变更**：
  - 广义包括主体、客体、内容变更。
  - 狭义通常不包括主体变更；主体变更往往就是“转让”的结果。
  - 本章主要讨论内容变更，尤其是不动产物权中需要登记的内容变更。
- **转让**：
  - 原型主要是所有权转让。
  - 也包括少数可独立转让的定限物权，如建设用地使用权。
  - 居住权不得转让；地役权通常随需役地或供役地转让，不作单独转让处理。
- **消灭**：
  - 物权与其主体或客体分离。
  - 包括绝对消灭与相对消灭。

> [!caution] 术语抓手
> “设立”多用于定限物权，“取得”多用于所有权；“主体变更”在结果上常与“转让”重合，狭义变更主要看内容变更。

## （二）原始取得与继受取得

| 类型 | 判断标准 | 典型情形 | 法律效果 |
| --- | --- | --- | --- |
| 原始取得 | 非依据他人既存权利而取得 | 生产、先占、添附、时效取得、善意取得 | 原则上取得较“干净”的权利，原权利负担不当然承继 |
| 继受取得 | 以前手权利为基础取得 | 买卖、赠与、继承、企业合并中的承继 | 继受前手法律地位，权利负担原则上随同承受 |

- 原始取得的意义主要存在于物权，尤其是所有权。
- 债权也可讨论取得，但“原始取得/继受取得”的复习价值远不如所有权。
- 善意取得虽然常基于受让人与无处分权人的交易行为，但通说仍将其定性为原始取得：
  - 受让人不是从真实所有权人处传来取得。
  - 法律直接配置所有权，以交易安全优先保护善意受让人。
  - 动产善意取得后，依据 [[民法典#第三百一十三条|民法典第313条]]，动产上的原有权利原则上消灭。

> [!tip] 区分抓手
> 原始取得与继受取得不是名词游戏，真正差别在于：受让人是否承受前手权利上的负担。继受取得“带负担继受”，原始取得则可能切断原有负担。

## （三）消灭、混同与抛弃

### 1. 消灭的类型

- **相对消灭**：权利从甲转移给乙，对甲而言消灭，对乙而言发生。
- **绝对消灭**：物权整体不再存在，如标的物灭失、期限届满、权利抛弃等。

### 2. 混同

- 债法上的混同：债权与债务同归一人，债权债务关系原则上消灭。
- 物权法上的混同：所有权人与定限物权人同归一人时，定限物权是否消灭。

课堂强调：传统上常说所有权吸收定限物权，但不宜机械化。若定限物权保留仍有交易功能或未来处分价值，不必当然否认其存续可能。

- 例：所有权人在自己房屋上设立居住权后转让所有权，以保留居住利益。
- 例：同一人有A、B两块地，先在B地上为A地设地役权，再转让B地，使新所有人承受地役权。

### 3. 抛弃

- **动产抛弃**：通常由单方抛弃意思加放弃占有完成。
- **不动产抛弃**：单纯搬离或不使用不足以消灭物权，通常需要向登记机关表示放弃并完成注销登记。

## （四）引起物权变动的法律事实

物权变动原因应先分为两类：

| 原因类型 | 是否以意思表示为中心 | 是否当然要求登记/交付 | 例子 |
| --- | --- | --- | --- |
| 基于法律行为 | 是 | 原则上要叠加公示要件 | 买卖、赠与、设立居住权、设立质权 |
| 非基于法律行为 | 否 | 不以登记/交付为发生要件，但处分时可能需补登记 | 裁判、征收、继承、合法建造、拆除 |

[[民法典#第二百二十九条|民法典第229条]]、[[民法典#第二百三十条|第230条]]、[[民法典#第二百三十一条|第231条]]构成物权编第二章第三节“其他规定”的核心：这些情形之所以是“其他”，正在于它们不是典型的基于法律行为发生的物权变动。

> [!caution] 易混点
> 公示原则不是说一切物权变动都必须登记或交付。公示要求主要控制的是**基于法律行为**发生的物权变动。继承、裁判、合法建造等情形中，权利可先因法律规定发生；之后处分该不动产物权时，再按 [[民法典#第二百三十二条|第232条]] 补足登记。

# 二、物权变动的公示与公信原则

## （一）公示原则的必要性

物权具有绝对效力和对世效力，物权变动会改变不特定第三人的法律处境。因此，物权变动需要一种外部可识别的事实，使第三人有机会知悉或调查物权状态。

- 不公示而承认完整物权效力，会使第三人无法预判交易风险。
- 公示制度的功能是降低信息成本、保护交易安全、使对世效力获得正当性。
- 物权法的底层逻辑可以概括为：**绝对性预设呼唤公示要求**。

与前章相连，物权法的三块基石可理解为：

1. 物权客体特定：明确支配对象。
2. 物权法定：固定权利类型与标准内容，降低识别成本。
3. 物权公示：使权利归属和变动具有外观。

## （二）公示方法：不动产登记与动产交付

[[民法典#第二百零八条|民法典第208条]]作原则宣示：

- 不动产物权的设立、变更、转让和消灭，依照法律规定登记。
- 动产物权的设立和转让，依照法律规定交付。

### 1. 不动产：登记

- 不动产不能移动、位置稳定，适合以登记簿反映权利归属与内容。
- 不动产登记簿是物权归属和内容的根据，见 [[民法典#第二百一十六条-第1款|民法典第216条第1款]]。
- 登记不仅有权利推定意义，还承载公示、公信和交易查询功能。

### 2. 动产：占有移转/交付

动产原则上不能建立类似不动产的完整登记系统，故传统上以占有和交付作为权利外观。

但课堂特别提醒：动产占有与交付的公示能力远弱于不动产登记。

- 占有更多是经验推定：占有人可能是所有权人，也可能是借用人、承租人、保管人、质权人。
- 交付往往瞬间发生，外部第三人未必能知道交付原因。
- 占有改定等交付替代形态更难说具有真实公示功能。

> [!note] 教材校准
> 刘家安《民法物权》也强调，动产占有和交付不像不动产登记簿那样直接呈现权利状态；其主要功能更接近权利推定和实际控制，而非完整、积极的权利公示。

## （三）公示生效主义与公示对抗主义

| 比较对象     | 公示生效主义                | 公示对抗主义                       |         |               |                       |                      |         |
| -------- | --------------------- | ---------------------------- | ------- | ------------- | --------------------- | -------------------- | ------- |
| 基本含义     | 未登记/交付，不发生物权变动效力      | 未登记/交付，物权变动可在当事人间发生，但不得对抗第三人 |         |               |                       |                      |         |
| 与物债二分的关系 | 更符合严格物债二分：未公示则停留在债权层面 | 容易出现“不具对抗力的物权”，体系上较模糊        |         |               |                       |                      |         |
| 中国法地位    | 原则规则                  | 例外规则                         |         |               |                       |                      |         |
| 典型条文     | [[民法典#第二百零九条-第1款      | 第209条]]、[[民法典#第二百二十四条        | 第224条]] | [[民法典#第二百二十五条 | 第225条]]、[[民法典#第三百七十四条 | 第374条]]、[[民法典#第四百零三条 | 第403条]] |

### 1. 原则：公示生效

- 不动产物权：依法登记，发生效力；未经登记，不发生效力，但法律另有规定除外。
- 动产物权：自交付时发生效力，但法律另有规定除外。

### 2. 例外：登记对抗

- 特殊动产：船舶、航空器、机动车等，未经登记不得对抗善意第三人。
- 地役权：自地役权合同生效时设立，未经登记不得对抗善意第三人。
- 动产抵押：抵押权自抵押合同生效时设立，未经登记不得对抗善意第三人。

> [!caution] 课堂批评
> 地役权作为不动产物权却采登记对抗，正当性并不充分；若只是以“减轻登记负担”为理由，难以解释为什么房屋买卖等不动产物权变动仍坚持登记生效。动产抵押登记对抗相对更容易解释，因为动产担保登记多采人的编成主义，公示效果本就弱于不动产登记。

## （四）公信原则与善意取得

公信原则，是指登记或占有等公示外观即使与真实权利状态不一致，信赖该外观并进行交易的善意第三人，在法律上仍可能获得与真实权利存在相同的效果。

- 公示解决“别人如何知道权利状态”。
- 公信解决“别人信赖公示外观后是否受保护”。
- 中国法没有以一般条款明文规定公信原则，而主要通过善意取得制度体现。

[[民法典#第三百一十一条|民法典第311条]]统一规定不动产和动产善意取得：

1. 受让时善意。
2. 以合理价格转让。
3. 应登记的已经登记，不需要登记的已经交付。

> [!tip] 复习抓手
> 公信原则不是让名义权利人拿登记外观对抗真实权利人；它保护的是信赖公示外观并进入交易的第三人。其价值选择是在静态财产安全与动态交易安全之间，优先保护后者。

# 三、物权变动的立法模式与物权行为

## （一）导入问题

甲将A物出售给乙，应连续追问三个问题：

1. **时间点**：所有权何时移转，是合同成立时、交付时，还是登记时？
2. **效力来源**：所有权因买卖合同移转，还是因履行阶段另有物权合意而移转？
3. **原因瑕疵**：买卖合同无效、被撤销时，已经完成的物权变动是否当然不发生或溯及消灭？

这些问题不能完全交给当事人意思解释解决：

- 普通当事人通常只表达经济目的，不会清楚区分债权效果与物权效果。
- 意思表示解释本身是法律问题，不只是事实问题。
- 物权变动具有涉他性，必须受法定公示与交易安全规则限制。

## （二）三种物权变动模式

| 模式 | 代表法系 | 物权何时变动 | 是否需要独立物权合意 | 原因行为无效时 |
| --- | --- | --- | --- | --- |
| 意思主义 | 法国、日本传统模式 | 买卖等债权合同成立/生效时 | 不需要 | 物权变动当然不发生 |
| 物权形式主义 | 德国、台湾地区通说 | 物权合意 + 登记/交付 | 需要 | 债权行为瑕疵原则上不影响物权行为效力 |
| 债权形式主义 | 奥地利、瑞士及我国通说倾向 | 有效债权合同 + 处分权 + 登记/交付 | 通常不承认独立物权合意，或至少不承认无因性 | 债权行为无效会使物权变动溯及不发生 |

### 1. 意思主义

- 买卖合同兼具债权效果和物权效果。
- 交付、登记通常只是对抗要件。
- 与严格物债二分不完全协调。
- 我国法不是标准意思主义，因为 [[民法典#第二百零九条-第1款|第209条]]、[[民法典#第二百二十四条|第224条]]都要求登记或交付。

### 2. 物权形式主义

物权变动需要：

1. 债权行为，如买卖合同。
2. 独立物权合意，如转移所有权的合意。
3. 登记或交付这一法定形式。

其核心是：

- **分离原则**：债权行为与物权行为相互独立。
- **抽象原则/无因性**：物权行为效力不受原因行为当然影响。

> [!note] “无因性”的准确理解
> “无因”不是没有原因，而是判断物权行为效力时，原则上“不问原因行为是否有效”。原因关系有瑕疵时，处分人可转向不当得利等债法请求权救济。

### 3. 债权形式主义

债权形式主义也称折中主义：

- 反对意思主义：单纯债权合同不足以使物权变动。
- 反对完整物权形式主义：通常不承认独立物权行为，或不承认物权行为无因性。
- 常见公式：**物权变动 = 有效债权合同 + 处分权 + 登记/交付**。

我国司法实践较多采债权形式主义。课堂提示，九民纪要执行部分体现了最高法院对买卖合同无效后出卖人享有物权性返还请求权的倾向，这与完整无因性理论并不一致。

## （三）我国法上的解释空间

我国民法典没有明文宣告采取哪一种物权变动模式。

可以确定：

- 我国不是意思主义。
- 处分权与登记/交付不是买卖合同生效要件。
- 买卖合同成立、生效本身不能直接带来所有权移转。
- 物权变动是否还需要一个独立物权合意，仍有解释空间。

[[民法典#第二百一十五条|民法典第215条]]的意义在于：

- 不动产物权变动合同自成立时生效。
- 未办理物权登记，不影响合同效力。
- 处分权、登记都不是债权合同生效要件。

但第215条不能直接推出完整的物权行为理论，因为它没有明确回答是否存在独立物权合意。

> [!caution] 易混点
> 第215条至少承认“债权合同效力”和“物权变动效力”可以区分；但不能过度解释为民法典已经完整采纳德国式分离原则与抽象原则。

## （四）物权行为与处分行为

### 1. 物权行为的定义

物权行为可从两种角度理解：

- 内容/目的说：以物权得丧变更为直接内容的法律行为。
- 构成方式说：由物权意思表示与外部变动特征（登记或交付）结合而成。

在复习中，更重要的是把物权行为放在**处分行为**之下理解。

| 类型 | 功能 | 是否需要处分权 |
| --- | --- | --- |
| 负担行为 | 产生债务、给付义务 | 不需要 |
| 处分行为 | 直接使权利发生、变更、消灭 | 需要 |

- 买卖合同作为负担行为，不因出卖人无处分权而当然无效。
- 物权行为若要发生处分效果，则须处分人有处分权，除非善意取得等制度补正。

### 2. 单方物权行为与双方物权行为

- 单方物权行为：典型是动产抛弃。
- 双方物权行为：典型是转移所有权、设立定限物权的物权合同。

课堂特别提醒：不能简单用“动产抛弃也是物权行为”来证明交易中的物权行为理论当然成立。分离原则、抽象原则讨论的核心前提，是具有给付方向的交易行为，即一方有意识使对方取得财产。

## （五）分离原则的解释力

### 1. 所有权保留

若设备买卖约定“价款付清前所有权保留”，若只承认一个买卖合同，会出现困惑：

- 买卖合同是否附条件？
- 若合同整体附条件，为什么买受人仍要付款、出卖人仍要交货？

若区分债权合同与物权合同，则结构更清楚：

- 债权合同立即生效，产生交货、付款义务。
- 物权变动合意附停止条件，待价款付清时发生所有权移转。

### 2. 简易交付

简易交付中，受让人已经占有动产。若借用人向出借人购买该物，合同成立时是否立即发生所有权移转？

- 若不承认独立物权合意，容易推导出买卖合同一生效，所有权立即移转。
- 但出卖人完全可能只是同意出卖，并未同意在价款支付前立即移转所有权。
- 承认物权合意，可以给当事人保留控制物权移转时间的工具。

> [!tip] 课堂抓手
> 物权行为理论不是为了日常交易添麻烦，而是在少数特殊场景中提供更精确的裁判工具。多数普通买卖中，债权合意、交付与物权合意可能高度重合；但特殊情形下，区分本身有解释价值。

## （六）无因性与交易安全

无因性规则的核心效果：

- 债权合同无效、被撤销，不当然摧毁已经完成的物权变动。
- 出让人丧失所有权后，主要向受让人主张不当得利等债法请求权。
- 后续交易不易被前手原因瑕疵层层击穿，有利于阻断交易链中的“多米诺效应”。

有因性规则的核心效果：

- 债权合同无效、被撤销，物权变动随之溯及不发生。
- 出让人仍可主张物上请求权性质的返还。
- 后手保护更多依赖善意取得。

我国现行实践总体不承认完整物权行为无因性，但课堂倾向认为：至少应承认债权合同之外独立物权合意的解释空间，以获得分离原则的清晰性；至于是否采完整无因性，可以另作限制或修正。

# 四、不动产物权变动与不动产登记

## （一）非依法律行为发生的不动产物权变动

| 情形 | 发生时间 | 法条 |
| --- | --- | --- |
| 裁判、仲裁、征收决定 | 法律文书或征收决定生效时 | [[民法典#第二百二十九条|第229条]] |
| 继承 | 继承开始时 | [[民法典#第二百三十条|第230条]] |
| 合法建造、拆除等事实行为 | 事实行为成就时 | [[民法典#第二百三十一条|第231条]] |

这些情形中，权利变动不是由生者之间的交易行为直接引起，故不能强行要求先完成登记才发生权利。

例：被继承人死亡后，其权利能力消灭，遗产物权不能处于真空状态；即使继承人在远方且尚不知情，也可依法律规定取得物权。

## （二）依法律行为发生的不动产物权变动

依法律行为发生不动产物权变动，原则上需要：

1. 处分人有处分权。
2. 有变动物权的意思表示。
3. 完成不动产登记。

[[民法典#第二百零九条-第1款|民法典第209条第1款]]是核心规则：未经登记，不发生不动产物权效力，但法律另有规定的除外。

### 居住权期限变更例

甲对房屋享有登记期限为2020年至2030年的居住权。甲与所有权人后来约定延长至2035年，但未办理变更登记。2031年房屋出售给丙，丙查登记簿发现居住权已到期。

- 甲与所有权人之间的延长期限约定，可能有债权效力。
- 但期限延长属于居住权内容变更，应登记才有物权效力。
- 丙信赖登记簿，不应受未登记延长期限的居住权对抗。

> [!caution] 易混点
> 居住权依 [[民法典#第三百六十八条|第368条]] 自登记时设立；期限延长等内容变更同样应进入登记。不能把合同、公证书与物权效力混为一谈。

## （三）不动产登记簿与权属证书

- 登记簿：物权归属和内容的根据。
- 权属证书：权利人享有不动产物权的证明。
- 二者不一致时，除有证据证明登记簿确有错误外，以登记簿为准。

登记的效力宜理解为强权利推定，而不是绝对真实。真实权利状态与登记可能不一致，此时需通过更正登记、异议登记、确权诉讼等机制处理。

## （四）更正登记与异议登记

[[民法典#第二百二十条|民法典第220条]]规定：

- 登记簿记载错误，权利人、利害关系人可申请更正登记。
- 登记权利人不同意更正的，利害关系人可申请异议登记。
- 异议登记后，申请人十五日内不起诉的，异议登记失效。

异议登记的功能：

- 向交易第三人提示登记权利状态存在争议。
- 削弱或排除登记簿外观的公信力。
- 并不当然“冻结”登记簿；登记权利人仍可能继续处分，但若异议成立，后续登记可能不发生物权变动效力。

> [!example] 遗嘱房屋例
> 甲死亡后，长子丙伪造遗嘱并登记为房屋所有权人。幼子乙申请异议登记并起诉。诉讼期间丙又卖房给丁。若丁未注意异议登记，通常难以主张善意取得，乙胜诉后可要求返还房屋。

## （五）预告登记

[[民法典#第二百二十一条|民法典第221条]]规定预告登记。

预告登记的功能，是使一项旨在将来实现不动产物权变动的债权请求权获得某种物权化保护。

- 典型场景：期房买卖中，买受人担心开发商一房二卖。
- 效力：预告登记后，未经预告登记权利人同意，处分该不动产的，不发生物权效力。
- 失效：债权消灭，或自能够进行不动产登记之日起九十日内未申请登记。

> [!tip] 复习定位
> 预告登记不是直接让买受人取得所有权，而是保全其将来取得所有权的债权请求权。它是“债权物权化”的典型制度。

# 五、动产物权变动与交付

## （一）动产物权变动的意义与要件

本节主要讨论两类动产物权变动：

1. 动产所有权转移。
2. 动产质权设立。

依法律行为发生动产物权变动，通常需要：

- 处分人有处分权。
- 有变动动产物权的意思表示。
- 完成交付或交付替代。

[[民法典#第二百二十四条|民法典第224条]]规定：动产物权的设立和转让，自交付时发生效力，但法律另有规定除外。

> [!caution] 条文限缩
> 第224条表述很抽象，但具体适用上主要对应动产所有权转让与动产质权设立。不动产也可能发生占有移转，但不动产占有交付不决定不动产物权变动。

## （二）交付的性质与构成

交付可理解为动产占有的移转。其构成通常包括：

1. 让与人依其意志放弃占有。
2. 受让人取得占有。
3. 受让人取得占有系由让与人的意愿促成。

关于交付的性质，有事实行为说与法律行为说之争。本章复习重点不在标签，而在于：交付作为动产物权变动的法定外部要件，使受让人取得事实控制并强化权利归属的外观。

## （三）现实交付与交付替代

| 类型 | 规则 | 例子 | 风险/考点 |
| --- | --- | --- | --- |
| 现实交付 | 让与人直接移转占有 | 甲把手机交给乙 | 最典型，公示和控制最强 |
| 简易交付 | 受让人已占有动产，法律行为生效时发生效力 | 乙借用甲电脑，后买下电脑 | “法律行为”是债权合同还是物权合意，涉及区分原则 |
| 返还请求权让与 | 第三人占有动产，让与人转让返还请求权代替交付 | 甲把借给乙的牛卖给丙，并转让对乙的返还请求权 | 是否通知第三人、请求权性质需区分 |
| 占有改定 | 出让人继续占有，受让人取得间接占有 | 甲卖牛给乙，又约定向乙租回继续使用 | 公示最弱；不能用于设立动产质权 |

### 1. 简易交付

[[民法典#第二百二十六条|民法典第226条]]：动产物权设立和转让前，权利人已经占有该动产的，物权自民事法律行为生效时发生效力。

例：甲将电脑借给乙，借用期间乙向甲购买，甲同意。

- 若将“民事法律行为”理解为买卖合同，则合同生效时即移转所有权。
- 若承认物权合意，则可进一步判断甲是否已经同意立即移转所有权。
- 课堂强调：简易交付是物权合意理论最有解释力的场景之一。

### 2. 返还请求权让与

[[民法典#第二百二十七条|民法典第227条]]：动产由第三人占有时，负有交付义务的人可以通过转让请求第三人返还原物的权利代替交付。

例：甲将耕牛借给乙，后卖给丙。甲对丙表示：“牛在乙处，我把要求乙返还的权利转让给你。”

复习问题：

- 返还请求权通常包括债权性返还请求权；是否包括物权请求权，需具体讨论。
- 通知第三人是否为物权变动生效要件，所有权转让与质权设立可能需要区分。

### 3. 占有改定

[[民法典#第二百二十八条|民法典第228条]]：动产物权转让时，当事人约定由出让人继续占有该动产的，物权自该约定生效时发生效力。

例：甲将耕牛卖给乙，乙要求交付，甲因农忙请求继续使用，并约定向乙租用两个月。

- 所有权转移可通过占有改定完成。
- 动产质权不能通过占有改定设立，因为质权设立要求质权人实际控制质物；若出质人继续直接占有，质权的控制和公示功能都落空。

## （四）特殊动产的物权变动

[[民法典#第二百二十五条|民法典第225条]]：船舶、航空器、机动车等的物权设立、变更、转让和消灭，未经登记，不得对抗善意第三人。

课堂强调，第225条应主要限于**特殊动产所有权转移**：

- 特殊动产仍是动产。
- 所有权转移仍原则上适用第224条，以交付发生效力。
- 登记只是对抗要件，而非生效要件。
- “善意第三人”主要指善意的后手交易相对人，不包括出卖人的一般债权人。

> [!note] 法条配合
> 《物权编解释（一）》第6条进一步说明：转让人转让船舶、航空器、机动车等所有权，受让人已支付合理价款并取得占有，虽未经登记，转让人的债权人主张其为第225条所称“善意第三人”的，不予支持，法律另有规定的除外。

## （五）动产抵押登记对抗

[[民法典#第四百零三条|民法典第403条]]：动产抵押权自抵押合同生效时设立；未经登记，不得对抗善意第三人。

- 动产抵押不移转占有，若强制以登记为设立要件，交易成本可能过高。
- 现代动产融资统一登记公示系统主要采“人的编成主义”，通过担保人名称检索担保信息。
- 该登记的公示精度弱于不动产登记，因此登记对抗主义较有现实解释空间。

## （三）三个最容易混淆的问题

> [!caution] 1. 公示不是所有物权变动的共同发生要件
> 公示原则主要控制基于法律行为发生的物权变动。裁判、继承、事实行为等变动可先因法律规定发生，但处分时可能需登记。

> [!caution] 2. 第215条不等于完整分离原则
> 第215条明确合同效力不受未登记影响，但并未明文承认独立物权合意，更未承认物权行为无因性。

> [!caution] 3. 第225条不是说特殊动产登记生效
> 船舶、航空器、机动车仍是动产；所有权移转原则上交付生效，登记只是对抗善意第三人。
