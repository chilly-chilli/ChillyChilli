* **定义**：民事法律关系是具有民事权利、义务内容的的社会关系。
* **引起**：民事法律关系由民事法律事实所引起，具有民法上的约束力。
* 民事法律关系之构成的要素：
	* 具有**法律上**的约束力
	* 具有**民法上**的约束力

---
# 民事法律关系的要素
	民事法律关系的构成要件，所有民事法律关系都具有的共性

## （一）主体
* 内涵：民事法律关系的参与者
* 外延：
	* [[1. 自然人]]
	* [[2. 法人]]
	* [[3. 非法人组织]]
> [!tip] 提醒
>有民事权利能力的：自然人、法人
>**无民事权利能力的：非法人组织**

## （二）内容
* 内涵：民事主体所享有的民事**权利**、承担的民事**义务**。

> [!notice] 权利/义务的产生依据：二元论
>法律的直接规定,*eg.侵权法律关系*
>当事人的约定,* eg.合同法律关系*


## （三）客体
* 内涵：民事权利与义务共同指向的对象

| 法律关系类型 |           客体            |         举例         |
| :----: | :---------------------: | :----------------: |
|   物权   |      （1）特定化的物（2）权利      | *（1）包括动产/不动产（2）质权* |
|   债权   |      行为（包括作为/不作为）       |      *竞业禁止协议*      |
|  人身权   | 人身利益（人格权-人格利益/身份权-身份利益） |                    |
|  知识产权  |          智力成果           |                    |
|  继承权   |           遗产            |                    |
